# 라이브러리로

## 코드 줄 수

빈 줄과 주석을 제외하면 5줄이다.

## 처리하기 어려웠던 부분

to_numeric()의 errors="coerce"가 숫자로 변환할 수 없는 값을 결측값으로 처리한다는 점을 이해해야 한다. 또한 groupby()로 과목별로 묶고 mean()으로 결측값을 제외한 평균을 구하는 함수 사용법을 알아야 한다.

# 차이

## 코드 줄 수

라이브러리 없이 작성한 코드는 31줄이고, pandas를 사용한 코드는 5줄로 26줄 더 짧다.

## 처리하기 어려웠던 부분

라이브러리 없이 작성할 때는 파일 읽기, 잘못된 점수 제외, 과목별 합계와 개수 저장, 평균 계산을 직접 구현해야 한다. pandas를 사용하면 같은 처리를 짧게 작성할 수 있지만, 함수의 사용법과 결측값 처리 방식을 이해해야 한다.

## 실행 결과

두 프로그램의 과목별 평균은 국어 75.78, 수학 82.83, 영어 82.00으로 같다. 두 방식 모두 수학의 빈 점수 2개와 영어의 미제출 1개를 평균 계산에서 제외한다.
영어 평균의 82.0과 82.00은 출력 형식만 다르고 같은 값이다.
